Création d’un site web avec Flexbox

Réalisation d’un site sur un sujet au choix, avec une mise en page responsive basée sur Flexbox.

Objectifs

  • Structurer les pages en HTML sémantique
  • Mettre en page avec Flexbox (header, sections, cartes)
  • Assurer le responsive (mobile/desktop)

Technologies

HTML CSS Flexbox

Réalisation

  • Layout principal en flex (sections, colonnes, alignements)
  • Cartes / blocs réutilisables
  • Media queries pour le responsive

Livrables

  • Code source + aperçu
  • Notes de conception (choix du layout)
Comment j’aurais mieux fait
  • Définir une grille de spacing (marges/paddings) plus cohérente
  • Renforcer l’accessibilité (focus visibles, contrastes, structure Hn)
  • Prévoir des composants réutilisables (cartes, boutons, sections)
