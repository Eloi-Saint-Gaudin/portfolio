Traitement de données : stats depuis OpenStreetMap

Site + traitement Python pour afficher des statistiques OSM (ex: bars, tabac, terrasses) via API.

Objectifs

  • Interroger OSM via une API (ex: Overpass)
  • Nettoyer/agréger les données en Python
  • Afficher des stats sur un site web

Idées de stats (exemples)

  • % de bars ayant une terrasse
  • % de commerces vendant du tabac
  • Comparaison par zone (ville/quartier)

Technologies

Python API OpenStreetMap Overpass HTML CSS JavaScript

Réalisation

  • Requêtes Overpass (tags OSM) et extraction
  • Traitement en Python (comptage, ratios, export JSON)
  • Affichage des stats côté front (cartes/compteurs)

Livrables

  • Repo (code Python + site)
  • Documentation de la requête API
Comment j’aurais mieux fait
  • Préciser le périmètre et les tags OSM (limites, biais, données manquantes)
  • Mettre en cache les résultats (API) et tracer les erreurs/requêtes
  • Ajouter des tests sur le traitement Python et un export JSON reproductible
