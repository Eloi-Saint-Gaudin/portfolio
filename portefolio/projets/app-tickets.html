Application de gestion de tickets d’intervention

Application web pour créer/assigner/suivre des tickets, avec base de données MySQL, UI Bootstrap et scripts Python.

Fonctionnalités (exemples)

  • Création / suivi de tickets (statuts, priorités)
  • Gestion des utilisateurs (selon le projet)
  • Historique et recherche
  • Exports / automatisations via Python

Technologies

PHP MySQL Bootstrap Python

Réalisation

  • Modèle de données (tables tickets/utilisateurs, relations)
  • CRUD côté PHP + requêtes SQL
  • Interface Bootstrap (formulaires, tableaux)
  • Scripts Python (imports, traitements, notifications…)

Livrables

  • Repo (code) + script SQL de création DB
  • Captures d’écran / doc utilisateur
Comment j’aurais mieux fait

  • Structurer l’API/les routes PHP et sécuriser (validation, requêtes préparées)
  • Ajouter des migrations SQL et une meilleure documentation d’installation
